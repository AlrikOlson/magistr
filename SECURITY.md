# Security policy

Magistr is an early development release. The project runs locally, and an agent runtime keeps its normal operating-system permissions. Do not use it with secrets or sensitive checkouts until you have reviewed the generated files, commands, provider configuration, and local workflow state.

## Reporting a vulnerability

Please do not open a public issue for an unpatched vulnerability. When the canonical GitHub repository is publicly reachable, use its **Security → Advisories** page for a private report. If that page is unavailable, contact the maintainer through the repository profile and include:

- the affected version or commit;
- the smallest reproduction or proof of impact;
- the provider, operating system, and project shape involved; and
- any suggested mitigation.

We will acknowledge a report when it is reachable, keep the report private while a fix is prepared, and document the released fix. Please allow time for investigation; this is a volunteer-maintained development project.

For ordinary bugs and feature requests, use the public issue tracker after checking that no sensitive data is included.
