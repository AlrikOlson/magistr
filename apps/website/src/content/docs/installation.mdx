Magistr's command-line program connects a project to your coding agent and manages
its saved work. This page installs the program. [Agent setup](/docs/agents) connects
it to a particular project.

import { version } from "../../../../../npm/magistr/package.json";

The current source preview is **v{version}**, for **Apple Silicon macOS 15 or
later**. Magistr has not been publicly released. The
[repository](https://github.com/AlrikOlson/magistr) is public, and npm and
Cargo registry packages are not published yet.

## Before you install

You need Git, Rust **1.95 or later**, and the macOS command-line build tools. Check Git and Rust in a terminal:

```sh
git --version
rustc --version
cargo --version
```

If the macOS build tools are missing, run `xcode-select --install` and finish
the system installer. Install and sign in to your coding agent separately;
Magistr does not provide an agent subscription.

## Build and install

In a terminal, choose a parent folder for the Magistr source checkout, then run:

```sh
git clone https://github.com/AlrikOlson/magistr.git
cd magistr
cargo install --locked --path crates/magistr-cli
magistr --version
```

Cargo builds the CLI and places the executable in Cargo's binary directory,
normally `~/.cargo/bin`. The source checkout is the copy of Magistr you build.
It can be separate from the project where you will use Magistr.

The last command should print the installed version. Confirm that help opens:

```sh
magistr --help
```

Installation alone does not connect any project or start implementation.

## If installation fails

| Symptom | What to do |
| --- | --- |
| Git reports that the repository is unavailable | Check your network connection and the repository URL in the clone command. |
| Rust reports an unsupported version | Install Rust 1.95 or later, then retry the locked build. |
| A compiler or linker is missing | Finish installing the macOS command-line build tools. |
| The shell cannot find `magistr` | Add Cargo's binary directory to your shell's `PATH`, reopen the terminal, and run `magistr --version`. |
| An older executable still runs | Use `command -v magistr` to check which installation the shell selects. |

Keep the complete build error if these steps do not resolve it. A connection
repair cannot fix a CLI that has not built successfully.
