# Installation

Magistr has not been publicly released. The current development version is v0.1.0, and interfaces and stored formats can change without backward compatibility. It builds from the [repository](https://github.com/AlrikOlson/magistr); there is no registry package yet. Use the desktop for conversations and the command line or connected agent for roadmap work.

> **Permission and privacy boundary**
>
> Magistr runs locally and keeps its state in the project. Your agent runtime keeps its own credentials and operating-system permissions; Magistr does not sandbox it. Review commands and generated files before using it on a sensitive checkout.

## Install

Requires Git and Rust 1.95 or later.

```sh
git clone https://github.com/AlrikOlson/magistr.git
cd magistr
cargo install --locked --path crates/magistr-cli
magistr --version
```

Cargo installs `magistr` into its binary directory, usually `~/.cargo/bin`.

## Initialize a project

Run initialization in the project you want to work on. It detects the stack and writes the project file and the agent setup.

```sh
cd ~/src/my-project
magistr init .
magistr --help
```

The command line lists commands with `magistr --help`.

## Open the desktop

On macOS, double-click **Launch Magistr.command** in the repository. On Windows,
double-click **Launch Magistr.cmd**. Building from the checkout requires Rust
1.95+, Node.js 22+ and the [platform build prerequisites](https://v2.tauri.app/start/prerequisites/).
The first build takes longer; later launches reuse compiled dependencies.

For an app that opens without build tools, download your platform's artifact
from a successful [desktop apps workflow](https://github.com/AlrikOlson/magistr/actions/workflows/desktop-apps.yml)
run. On macOS, open the disk image and drag **Magistr** to **Applications**.
On Windows, run the setup executable and open **Magistr** from the Start menu.
These development packages are not publicly signed or notarized.

You can also build a package yourself with `node scripts/desktop.mjs package`,
or open a particular folder directly:

```sh
node scripts/desktop.mjs open --dir /path/to/project
```

The desktop opens projects, working copies and separate conversations. Send a
message, answer permission requests or stop work while keeping your draft.

## The project file

`magistr init` creates `.magistr/project.json`. It records the commands Magistr runs as quality gates, any required custom gates, the test conventions and the roadmap settings. Change only the values your project needs. The roadmap itself is stored by Magistr inside `.magistr/`.

## Connect an agent

Claude Code setup is always written. Add other agents with `--agent`, which accepts `codex`, `copilot`, `cursor`, `cline`, `windsurf` and `aider`, separately or combined:

```sh
magistr init . --agent codex --yes
./.codex/run
```

For Claude Code, run `magistr init . --yes`, then launch `claude` in the project.

The setup installs the workflow commands the agent uses: `/next` (Codex: `$next`) resumes an interrupted work item or starts the next ready one, then stops after that item; `/roadmap-refresh` reshapes the roadmap without implementing anything; `/validate` runs the configured checks.

## Run one work item

```sh
magistr next
```

Resumes an interrupted work item or starts the next ready one, and records what happened. `magistr next-loop` continues through fresh agent sessions, one work item per session, up to `--max-iterations` (default 10).
