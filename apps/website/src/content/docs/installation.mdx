# Installation

Magistr is an early development release (v0.1.0). Build it from the [repository](https://github.com/AlrikOlson/magistr) while the package release process is being completed.

> **Permission and privacy boundary**
>
> Magistr runs locally. Your agent runtime keeps its own credentials and operating-system permissions; review commands and generated files before using it on a sensitive checkout.

## Build from source

```sh
git clone https://github.com/AlrikOlson/magistr.git
cd magistr
cargo install --locked --path crates/magistr-cli
magistr --version
```

## Configure a project

```sh
cd ~/src/my-project
magistr init .
magistr
```

For Codex:

```sh
magistr init . --agent codex --yes
./.codex/run
```

## Release archives

Release archives and checksums are tracked in the [release-inventory.md](https://github.com/AlrikOlson/magistr/blob/main/docs/release-inventory.md). The desktop viewer is experimental and is not part of the main-branch package.
