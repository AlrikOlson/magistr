# Installation

Connect Magistr to a project and keep using Codex or Claude Code. The command line adds project setup, planning, source tools and recorded checks.

**Source preview · v{version} · Apple Silicon macOS.** npm and Cargo registry packages are not published yet. Building the preview requires access to the [repository](https://github.com/AlrikOlson/magistr), which is not publicly accessible yet. The desktop is a separate preview available from source.

> **Your code and permissions**
>
> Magistr runs on your Mac and saves plans and progress with your project. Your agent still uses its own account and can run commands with the permissions you give it. Review proposed commands and file changes before approving them.

## Install the preview

Requires macOS 15 or later on Apple Silicon, Git, Rust 1.95 or later, and the macOS command-line build tools. Install and sign in to Codex or Claude Code separately.

```sh
git clone https://github.com/AlrikOlson/magistr.git
cd magistr
cargo install --locked --path crates/magistr-cli
magistr --version
```

Cargo installs `magistr` into its binary directory, usually `~/.cargo/bin`. Add that directory to your PATH if the command cannot be found.

## Set up your project

In the project you want to work on, run:

```sh
cd ~/src/my-project
magistr init .
```

Setup recognizes your project, lets you choose one or more agents, and shows the test commands and file changes before applying them. **Setup adds files only for the agents you choose.** It keeps your custom settings, instructions, other tool connections and saved work.

Setup checks that the agent can connect to Magistr and read your project. It finishes with a starter prompt to inspect the project and propose a plan. **Setup does not start implementation.** If an agent is unavailable, follow the reported installation or sign-in instructions; you can still prepare its setup files.

To preview a specific selection without writing files:

```sh
magistr init . --agent codex,claude --dry-run
```

Use `--yes` instead of `--dry-run` to accept the setup defaults without prompts. Running setup again keeps your saved work and custom settings.

## Connect Codex

Choose Codex during setup, or connect it directly:

```sh
magistr init . --agent codex --yes
./.codex/run
```

The launcher loads the project's instructions, skills and Magistr connection. Start a new agent session after changing setup.

## Connect Claude Code

Choose Claude Code during setup, or connect it directly:

```sh
magistr init . --agent claude --yes
claude
```

Claude Code reads the Magistr connection from `.mcp.json` and the project instructions and skills from `CLAUDE.md` and `.claude/`. Approve the project's MCP connection when Claude Code prompts you.

## Connect another agent

Choose **Another MCP agent**, or run:

```sh
magistr init . --agent portable --yes
```

MCP is the connection between your agent and Magistr. This command saves its settings to `.mcp.json` and instructions to `.magistr/instructions.md`. If your agent does not read those files, copy the Magistr connection into its MCP settings and load the instructions.

The connection launches `magistr mcp --dir /path/to/project`. Your agent can use it to find and edit source, plan the work, save progress and run checks.

Optional project instructions are also available with `--agent cursor`, `copilot`, `cline`, `windsurf` or `aider`. Select multiple agents with commas or repeated `--agent` options.

## Check or repair setup

```sh
magistr doctor .
magistr repair . --dry-run
magistr repair .
```

`doctor` explains missing setup, settings it cannot read, unavailable agents and connection problems. It gives you commands to fix them. Repair shows its proposed changes and keeps customized files and other tool connections. Magistr changes setup files only when you run setup or repair.

Project settings live in `.magistr/project.json`, including test commands and required checks. Your plans and work history stay inside `.magistr/`.

## Upgrade the preview

From your Magistr source checkout, update and reinstall:

```sh
git pull --ff-only
cargo install --locked --path crates/magistr-cli --force
```

Then run `magistr doctor .` and `magistr repair .` in each project to review and update its setup.

## Remove setup or uninstall

Review and remove the agent setup in each project:

```sh
magistr remove . --dry-run
magistr remove .
```

Removal keeps project settings, work history, customized files and other tool connections. The report lists the files it kept. To uninstall the command after removing agent setup:

```sh
cargo uninstall magistr-cli
```

## Start work when you are ready

Ask your agent to inspect the project and propose a plan first. Use `$next` in Codex or `/next` in Claude Code when you want to implement one ready roadmap item. The skill resumes interrupted work before starting another item.

From the command line, `magistr next` runs one work item. `magistr next-loop --max-iterations 5` continues through up to five fresh agent sessions. `magistr validate` runs the configured checks.

## Try the desktop preview

The desktop is a separate preview; installing the `magistr` command does not install the app. On macOS, open **Launch Magistr.command** in the source checkout. Building it requires Rust, Node.js and the [platform build prerequisites](https://v2.tauri.app/start/prerequisites/). The preview is not signed or notarized for public distribution.

See the [development guide](https://github.com/AlrikOlson/magistr/blob/main/docs/development.md) for build and packaging commands, or learn [how Magistr works](/docs/concepts).
