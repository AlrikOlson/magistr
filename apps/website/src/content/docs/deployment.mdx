# Deployment

The Astro site lives in `apps/website` and deploys to the existing Cloudflare Pages project `magistr`.

```sh
cd apps/website
npm ci
npm run build
wrangler pages deploy dist --project-name magistr --branch main
```

Verify [magistr.dev](https://magistr.dev), [/docs/installation](https://magistr.dev/docs/installation), and [/robots.txt](https://magistr.dev/robots.txt) after a deploy.
