# Deployment

The website lives in `apps/website` and deploys to the Cloudflare Pages project `magistr`, whose production alias is [magistr.dev](https://magistr.dev).

```sh
cd apps/website
npm ci
npm test
wrangler pages deploy dist --project-name magistr --branch main
```

`npm test` builds the site and checks the built output: the pages, the screenshot manifest and image hashes, the metadata and the caching headers.

After a deploy, verify [magistr.dev](https://magistr.dev), [/docs/installation](https://magistr.dev/docs/installation) and [/robots.txt](https://magistr.dev/robots.txt) respond, and check the pages on a phone and a desktop in both themes.
