# Deployment

The public site is built from `apps/website` and served by Cloudflare Pages.

## Local preview

```sh
cd apps/website
npm ci
npm run dev
npm run build
npm run preview
```

The production project is **magistr**. The canonical host is [magistr.dev](https://magistr.dev); `magistr.pages.dev` remains the Pages project URL.

## Verify a deploy

Check the homepage, an installation page, and the crawler policy after each release:

- [https://magistr.dev/](https://magistr.dev/)
- [https://magistr.dev/docs/installation](https://magistr.dev/docs/installation)
- [https://magistr.dev/robots.txt](https://magistr.dev/robots.txt)

The site emits canonical URLs, Open Graph metadata, a sitemap, and a `robots.txt` reference to that sitemap. Deployment credentials and DNS belong to the existing Pages project; do not add a second hosting system.
