# Skills

Magistr installs project skills for planning, implementation, and verification.

- Codex uses `$next`, `$roadmap-refresh`, and `$validate`.
- Claude Code uses `/next`, `/roadmap-refresh`, and `/validate`.

`$next` (or `/next`) carries one ready roadmap chunk through the project workflow and stops. `$roadmap-refresh` reshapes the roadmap without implementing a chunk. `$validate` runs the configured checks.

The generated skills live in the agent configuration directory created by `magistr init`. See the [repository skill templates](https://github.com/AlrikOlson/magistr/tree/main/crates/magistr-cli/templates/workflows) when you need implementation details.
