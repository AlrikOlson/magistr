# Configuration

`magistr init` creates `.magistr/project.json` in the project you want to manage. It records the commands and workflow settings Magistr needs.

Native roadmap state is authoritative. Keep `roadmap_exports: false` so Magistr does not create `ROADMAP.md` or `ROADMAP.json`.

Start with the generated file and change only values your project needs. The [repository development guide](https://github.com/AlrikOlson/magistr/blob/main/docs/development.md) explains the current checks.

```sh
magistr init .
```

See [installation](/docs/installation) for setup and [skills](/docs/skills) for the workflow.
