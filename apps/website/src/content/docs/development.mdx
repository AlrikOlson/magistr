# Development

Magistr is a Rust workspace. Use the [repository development guide](https://github.com/AlrikOlson/magistr/blob/main/docs/development.md) for the current contributor notes.

```sh
cargo fmt
cargo check --workspace --all-targets
cargo nextest run --workspace
cargo clippy --workspace --all-targets -- -D warnings
```

For the website:

```sh
cd apps/website
npm ci
npm test
```

Keep the shared interface independent of terminal transport details and the desktop independent of `magistr-tui`.
