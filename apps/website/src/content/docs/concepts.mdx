# How Magistr works

Magistr keeps track of what you want to build, what your agent has done and which
checks passed. Start another session and continue from that record.

## Your plan

A roadmap breaks the project into steps. Each step has a goal, a priority, any
work it depends on and the checks it needs to pass. Your agent can help you add,
reorder or revise the plan.

Use `$next` in Codex or `/next` in Claude Code to continue unfinished work or
complete one ready step. The agent reads the saved plan before continuing and
stops after that step. Asking for a plan does not start implementation.

From the command line, `magistr next` runs one step. To work through several steps
with a fresh agent session for each, set a limit:

```sh
magistr next-loop --max-iterations 5
```

## Your work history

As the agent works, it saves the plan, changes, findings and check results.
That history helps the next session understand what happened and what to do next.

Related findings stay together. Later findings can correct earlier ones, and
useful findings can be pinned to keep them easy to find. A checkpoint saves a
place in the work that the agent can return to.

## Checking your work

A step is done when it meets its goal and the required checks pass. For a small
change, run the relevant formatting, build, lint and test commands. Run the full
suite when you ask for it or when a change affects the whole project.

Each check saves the command and whether it passed. A failed required check keeps
the step open so the agent can fix the problem and check it again.

```sh
magistr validate
```

Set the project's test commands and required checks during setup, or edit them in
`.magistr/project.json`.

## Agent sessions

Each session is a conversation with an agent in a copy of your project. Switching
sessions keeps their work and unanswered permission requests in place.

Saved conversations include the model, latest reply and whether the work
finished. The ability to resume a conversation depends on the agent you use.

## The desktop preview

The desktop is a separate preview available from source. It gives you a place
to talk to your agent and return to project conversations. Use the command line
or your connected agent for planning, reviewing changes and project setup.

Open a configured project in `magistr-desktop`. Choose **New session** to start a
conversation. Switch between projects or copies of a project, then return to a
session to continue reading and recover your draft.

Press Return to send a message, or Shift Return for a new line. **Stop** cancels
the current turn and keeps your draft. Permission requests let you approve or
decline the requested action. **Copy conversation** copies its messages.
**Close session** ends that conversation; Quit closes the app and its running work.

Choose System, Light or Dark under **Appearance**. Text fields support selection,
the clipboard and your input methods.

## Where your work is saved

Setup adds your project settings and the files your chosen agents need.
Plans, progress and findings stay under `.magistr/` in your project.
Saved conversations also use Magistr's local data folder.

See the [installation guide](/docs/installation) to set up an agent, check the
connection or remove Magistr from a project.
