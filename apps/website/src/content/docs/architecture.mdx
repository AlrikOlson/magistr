# Architecture

Magistr is a Rust workspace with native project state and several clients.

| Crate | Owns |
| --- | --- |
| `magistr-domain` | Domain concepts and invariants |
| `magistr-application` | Use cases and ports |
| `magistr-engine` | Persistence and workflow execution |
| `magistr-cockpit` | Shared interface model |
| `magistr-tui` | Terminal client |
| `magistr-mcp` | MCP tools |
| `magistr-cli` | The `magistr` command |

The cockpit stays independent of terminal protocols. The desktop client stays independent of `magistr-tui`. For the full map, read the [repository architecture overview](https://github.com/AlrikOlson/magistr/blob/main/docs/architecture/overview.md).
