# Hooks

Optional hooks live in the `lifecycle_hooks` field of `.magistr/project.json`.

A hook runs a command or Magistr tool at a lifecycle event such as `on_enter` or `on_exit`. Keep hooks small and review them like any other project automation.

The repository source is the authority for the complete hook contract.
