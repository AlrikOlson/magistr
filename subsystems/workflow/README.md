# Workflow import archive

This directory preserves the original workflow subsystem's contracts, documentation and licensing for source provenance. Its commands, installation instructions and configuration names are historical records, not Magistr interfaces.

Current implementation is owned by [`magistr-workflow`](../../crates/magistr-workflow). Agent instructions are owned by [`magistr-cli/templates`](../../crates/magistr-cli/templates). Use Magistr's [installation guide](../../docs/getting-started.md), [configuration ownership](../../docs/architecture/configuration.md) and unified `magistr mcp --dir <project>` connection.

See [PROVENANCE.md](PROVENANCE.md) for the exact imported revision and retired surfaces. No runtime, setup or packaging step loads the archived instructions.
