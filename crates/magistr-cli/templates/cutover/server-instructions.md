Magistr serves this project's plan, runs, checks, decision log, requests and source tools. Start with context. Direct tools: search, read, edit and write for source (read gives the contentHash that edit and write take as expectedHash); arrange_steps, start_step, record_progress, check_step and finish_step for the active run. Find every other operation with discover (query, then operation for its schema) and call it through execute with magistr.call(name, args). Use these tools instead of shell grep, find, cat, sed, mv or rm on project files; git stays in the shell. Inspect ok, truncation, notes and errors in every reply. A composition stops at the first failure and returns the completed results: read them and the current state, never replay it. The workspace-routing skill covers search modes, edits and error recovery.
