# Code of Conduct

Magistr is a small project built in public. We want issues, discussions, reviews, and pull requests to be useful and welcoming to people with different backgrounds and levels of experience.

## Expected behavior

- Be respectful and assume good intent while staying open to correction.
- Explain disagreement with evidence and focus on the work.
- Give actionable feedback about code, documentation, and user experience.
- Protect private information and do not post credentials, logs, or sensitive checkouts.

## Unacceptable behavior

Harassment, discrimination, personal attacks, sexualized language or imagery, threats, doxxing, and deliberate disruption are not acceptable. Project maintainers may remove content or restrict participation when needed to keep the project safe and workable.

## Reporting a concern

If you see behavior that violates this code, contact the maintainers through the repository profile or a private GitHub channel rather than escalating in a public thread. Include links or context that can be reviewed without sharing private data. Security reports belong in [SECURITY.md](SECURITY.md), not in a public issue.

This code is a practical project standard and may be refined as the community grows.
