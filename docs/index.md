# Magistr documentation

Magistr is in early development. Keep the public surface small while the first real release is being prepared.

## Start here

- [Installation](https://magistr.dev/docs/installation) — build from source and initialize a project.
- [Configuration](https://magistr.dev/docs/configuration) — see the one project file Magistr creates.
- [Skills](https://magistr.dev/docs/skills) — use the agent workflow commands.
- [Architecture](https://magistr.dev/docs/architecture) — see the Rust crate boundaries.
- [Development](https://magistr.dev/docs/development) — run the checks.
- [Deployment](https://magistr.dev/docs/deployment) — maintain the Astro site.

The [website](https://magistr.dev) is a short product introduction. Detailed contracts and release records remain in the repository, including the [architecture notes](architecture/overview.md), [release inventory](release-inventory.md), and [development guide](development.md).

Native roadmap state uses the `think-and-ship` backend. Keep `roadmap_exports: false`; do not create `ROADMAP.md` or `ROADMAP.json`.
