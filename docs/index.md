# Magistr documentation

Magistr is in early development. The public surface is kept small while the first real release is being prepared.

## For users

- [Installation](https://magistr.dev/docs/installation) — install, initialize a project and connect an agent.
- [Concepts](https://magistr.dev/docs/concepts) — roadmap, sessions, recorded work, verification and project state.

## For contributors

- [Getting started](getting-started.md) — the longer setup walkthrough, including Codex.
- [Development](development.md) — the contributor commands, the gates, the terminal goldens, the website and its deployment.
- [Architecture](architecture/overview.md) — crate ownership, boundaries and the client and host contracts; the [terminal architecture](architecture/terminal.md) covers the interface.
- [Release inventory](release-inventory.md) — what the release contains and the release checklist.
- [Benchmark pilot](benchmark-pilot-september-2026.md) — September 2026 benchmark research, protocol, and evaluation evidence.

Native roadmap state uses the `magistr` backend. Keep `roadmap_exports: false`; do not create `ROADMAP.md` or `ROADMAP.json`.
