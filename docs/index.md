# Magistr documentation

Magistr is in early development. The public surface is kept small while the first real release is being prepared.

## Start here

- [Installation](https://magistr.dev/docs/installation) — build from source, initialize a project and connect an agent.
- [Concepts](https://magistr.dev/docs/concepts) — roadmap, sessions, recorded work, verification and project state.
- [Architecture](https://magistr.dev/docs/architecture) — which crate owns what, and the client and host boundaries.
- [Development](https://magistr.dev/docs/development) — the contributor commands and checks.
- [Deployment](https://magistr.dev/docs/deployment) — build, verify and deploy the website.

The [website](https://magistr.dev) is a short product introduction. Detailed contracts and release records remain in the repository: the [architecture notes](architecture/overview.md), the [terminal architecture](architecture/terminal.md), the [release inventory](release-inventory.md), the [getting started guide](getting-started.md) and the [development guide](development.md).

Native roadmap state uses the `think-and-ship` backend. Keep `roadmap_exports: false`; do not create `ROADMAP.md` or `ROADMAP.json`.
