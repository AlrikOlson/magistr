# Focus reveal correction

Accepted for the tested headless WebKit states. Focusing an item below the viewport now brings it into view with the normal small margin; the shared camera no longer subtracts the old footer allowance after the viewport has already excluded it. This correction follows commit `f89eb659`.

The 16 affected interface and gallery tests pass, including three regression scenarios for Roadmap, Reasoning and Projects. All 170 captures retain their source-bound receipts. Ten new or changed images were opened from this folder and inspected; 160 are exact PNG hash matches to individually reviewed archive images, with explicit references below and in the [131-image gallery review](gallery/review.md). No hash match is claimed as a fresh visual inspection.

Focused scenes intentionally pan items outside the viewport before moving keyboard focus. The target is then fully visible with a clear focus ring and a small gap above the controls. Other offscreen content remains reachable with pan or Fit all. Review covers legibility, framing, ports, routing and footer clearance in both appearances. No native OS-input, Tauri integration, IME, assistive-technology or Windows claim.
