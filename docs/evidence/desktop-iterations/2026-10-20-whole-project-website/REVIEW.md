# Visual review: 2026-10-20-whole-project-website

Task: redesign the whole public website and guides around building larger projects with Magistr; show the real roadmap, saved reasoning, chunked work and checks.

Reviewed every saved frame from this directory using the image viewer. Full-page overviews were checked for overall flow and paired with the original-size region and reading-detail captures for legibility. Metadata, exact source hashes, viewport sizes, appearance, renderer/version, capture times and image hashes are in [browser-checks.json](browser-checks.json). That machine report retains its original pending-review markers; this document records the actual review.

**Iteration verdict: FAIL; retained for comparison.** The introduction delays the visual example, the loop command contains a literal newline, and the compact roadmap caption refers to arrows that are not shown. The next iteration corrects those areas.

The nine-route browser run passed in four profiles. This does not substitute for the visual findings below. Desktop and compact, light and dark, selected records, dependencies, alternatives, failed checks, navigation, search recovery and reflow were inspected. No foreground OS-input or assistive-technology testing was performed. The website's explanatory graphs are dated real records, not a representation of a finished desktop planning screen.
