# Find conversation row actions

Inspected: 20-actions-dark.png, 20-actions-light.png, 20-actions-compact.png.

Actions are visible without hover and open within their conversation row. The initial compact capture exposed a clipped floating menu; replacing it with an expanding row keeps the complete action visible. Keyboard Escape restores the trigger and background actions retain their session target.

Receipts beside each image identify exact source hashes, viewport, theme, renderer and capture time. Background WebKit uses production interface code with isolated fixtures. Native input, Rust command integration, VoiceOver and Windows parity were not exercised.
