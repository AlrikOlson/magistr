# Answer requests in compact panels

Inspected: 25-request-dark.png, 25-request-light.png.

A request with fifty detail lines keeps Allow once and Decline beside the title and bounded detail reader. Full source remains scrollable and copyable. The answer command targets the selected sync conversation.

Receipts beside each image identify exact source hashes, viewport, theme, renderer and capture time. Background WebKit uses production interface code with isolated fixtures. Native input, Rust command integration, VoiceOver and Windows parity were not exercised.
