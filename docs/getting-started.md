# Getting started with Magistr

The [product manual](https://magistr.dev/docs) owns the current user instructions.
Magistr is a source preview; installation requires repository access.

1. [Install the CLI](https://magistr.dev/docs/installation).
2. [Connect Codex, Claude Code, or another agent](https://magistr.dev/docs/agents).
3. [Complete a first task](https://magistr.dev/docs/workflow).

For ongoing work, see [planning](https://magistr.dev/docs/roadmap),
[chunks](https://magistr.dev/docs/chunks),
[verification](https://magistr.dev/docs/verification), and
[resuming sessions](https://magistr.dev/docs/sessions).

For maintenance, see [configuration](https://magistr.dev/docs/configuration),
[storage and backups](https://magistr.dev/docs/storage),
[troubleshooting](https://magistr.dev/docs/troubleshooting),
[upgrades](https://magistr.dev/docs/upgrades), and
[removal](https://magistr.dev/docs/uninstall).

Changing Magistr itself? Use the [development guide](development.md) and
[contributor index](index.md).
